Episodic Memory按「经历」存的记忆——某次做了什么、结果如何。Reflexion 的复盘就存在这儿
Semantic Memory按「事实」存的记忆——规则、偏好、领域知识，与具体哪次经历无关

2三组最容易混的

Prompt / Context / Memory三个词常被当成一个

Prompt 是这次递给它的那叠纸；Context 是这叠纸里它真的能读到的部分；Memory 是纸外面那个库，需要时才取一页进来。

Workflow / Agent / RPA分界在「谁决定下一步」

Workflow 是流程写死；Agent 是下一步由它判断；RPA 是录好的操作回放，遇到没录过的界面就卡住。

CoT / ReAct / Reflexion / ToT四个不同位置的补丁

四个都在补「想得更好」，但补的位置不同：CoT 补「不写步骤」，ReAct 补「不接地」，Reflexion 补「不记教训」，ToT 补「不回头」。

本页要点

  1. Harness 是外面那层程序，Tool 是它能按的按钮，Grounding 是答案有出处。
  2. Prompt / Context / Memory 三者的区别：递进去的、读得到的、存在外面的。
  3. CoT、ReAct、Reflexion、ToT 是四个不同位置的补丁，不是四个版本的同一样东西。

★自测

Q1Harness 和 Tool 的区别是什么？
Harness 决定「怎么循环、怎么重试、什么时候停」，Tool 是循环里被调用的东西。
Q2Episodic Memory 存的是什么？
Reflexion 的复盘就是典型的情景记忆——它记的是一次具体的失败，不是通用规则。
