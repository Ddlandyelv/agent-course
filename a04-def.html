0.4第零幕 · 它到底是什么·TWO DEFINITIONS

两个定义，一个分水岭

一个来自教科书，讲结构；一个来自工程界，讲零件。把它们叠在一起，就能看清大模型到底改变了哪一环——决策。

1定义一：能感知、能行动的东西

教科书里的定义来自 Russell 与 Norvig 的《人工智能：一种现代方法》：

「任何通过传感器（sensor）感知其环境（environment），并通过执行器（actuator）作用于该环境的事物，都可以被视为一个智能体。」Russell & Norvig

按这个定义，恒温器也是 Agent：温度计是传感器，开关是执行器，它维持室温。所以这个定义只规定结构，不规定智能——它说的是「有闭环」，不是「会思考」。

感知从环境取信息
→
决策决定做什么
→
行动作用于环境

这个闭环里最关键、也最难的是中间那个「决策」。恒温器的决策是一行 if：温度低于 26 度就开。而真实的决策需要理解目标、拆解步骤、应对意外——这正是大模型之前做不到的部分。

2定义二：四件套

2023 年，Lilian Weng 给出了一个在工程界流传极广的公式：

Agent = LLM + memory + planning + tool use
部件管什么没有它会怎样
LLM理解、推理、组织语言没有决策能力，只是一段脚本
memory记住对话、记住做过什么每轮从零开始，重复犯错
planning拆任务、排顺序、判断先做哪步遇到多步任务就卡住
tool use查询、计算、调接口、改文件只能说不能做

这个公式的价值不在精确，而在可拆解：它把「智能体」这个模糊的词，拆成了四个可以分别实现、分别出错的工程模块。

3分水岭：从执行器到思考者

两个定义之间隔了二十年，中间的变化只有一句话：

决策那一环，从人写死的规则，变成了模型自己推理。

大模型给「决策」这一环带来了四样传统算法给不了的东西：

带来了什么具体表现
推理与规划能把「订一次旅行」拆成查预算、查天气、比价、改方案
自然语言即接口不需要把世界翻译成符号，用户怎么说它就怎么理解
临场应变接口报错能读错误信息，换个思路再来
自我解释能说出自己为什么这么做，这让排错第一次成为可能

而恒温器满足「能感知能行动」，不满足「自己决定下一步做什么，并且真的去做」。所以严格说：恒温器是 Agent，但不是智能体——两个词在中文里常被当成一个，这里按前一个定义用。

本页要点

  1. 教科书定义只讲结构：感知 → 决策 → 行动，恒温器也算。
  2. 工程定义（Lilian Weng）讲零件：LLM + memory + planning + tool use。
  3. 分水岭在「决策」：从人写死的规则，变成模型自己推理。
  4. 后面所有章节都是在补四件套里的某一格。

★自测

Q1按教科书定义，恒温器算不算 Agent？
教科书定义只规定结构不规定智能。恒温器满足闭环，所以算；但它不具备「临场决策」，所以不是智能体。
Q2Lilian Weng 那个公式的真正价值是什么？
它的价值在可拆解、可归因：出问题时你能说出是哪一格坏了，而不是笼统地说「Agent 不行」。
