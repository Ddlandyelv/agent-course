6怎么读：顺着「问题」读，不顺着年份读

别顺着读，要顺着「问题」读。先想清楚你手上的 Agent 现在卡在哪：

你现在的毛病直接跳哪一篇
算不对、多步就崩CoT → Self-Consistency
张口就编，不去查ReAct → Toolformer
改完不见好，凭感觉调Self-Refine → Reflexion
长任务做到一半忘了前面Generative Agents → MemGPT
复杂题一次想错就整条废Tree of Thoughts → LATS
说不清自己的 Agent 弱在哪AgentBench → 四模块综述

十三篇一次读完没有意义。带着一个具体的毛病去读，一篇就够用。每篇的「方法」一节通常只有两三页，比任何二手总结都短。

本页要点

  1. 十三篇各回答一个问题：能算对吗、能动手吗、能变好吗、能记住吗、能选对路吗、靠不靠得住。
  2. 四组递进：写出来 → 动起来 → 越干越好 → 走向生产。
  3. 读法是顺问题读，不是顺年份读。
  4. 每篇都给 arXiv 编号，直接搜编号就能下原文。
