07第二部分 · 从会说话到会动手·SELF-REFINE & REFLEXION

让失败变成经验

错了不会改，是 Agent 最难缠的毛病。这一页讲两条修法：写完自己批，和把失败写成复盘带到下一轮——以及它们共同的命门。

10 分钟 含论文数字 两条修法
这一页在能力栈上的位置
对应环节能力层 · 自我修正
不学卡在哪同一类错误反复出现，改了提示也没用，因为系统里没有「上次错在哪」这一项。
它解决什么把失败固化成可复用的文字经验，让第二次尝试真的不一样。

1缺什么：错了不自知

ReAct 跑完一轮就结束了，错了也白错。下一轮重来，还是同样的错——因为它根本不记得上次为什么错。

2023 年上半年有两篇论文在补这个洞，思路不同：一篇让它写完自己批，一篇让它把失败写成复盘带进下一轮。

2Self-Refine：写完不要直接交

同一个模型演三个角色：先当生成者写初稿，再当批评者挑具体毛病，最后当修改者照意见改。循环几轮，不改任何权重，全靠提示。

生成写初稿
→
批评挑具体问题
→
修改照意见改
→
再来一轮直到没问题

7 个任务上平均提升约 20 个百分点；人类评估明显更偏好改过之后的版本。

局限：自己评自己，评不出自己没意识到的错。没有外部信号时，会越改越偏还自我感觉良好。

3Reflexion：把失败写成一段话

沿用 ReAct 的循环，但每次行动后算一个分数，判断这次是不是白走了；命中就终止、重置环境，并把这次的失败写成一段复盘带进下一轮。

Actor干活
→
Evaluator判分
→
Self-Reflect写复盘
→
Memory存起来 → 下轮先读
关键数字值
HumanEval pass@191%（同期 GPT-4 基线约 80%）
ALFWorld134 个任务完成 130 个
复盘条数1–3 条就够，多了挤占上下文

作者把它叫「语言强化学习」——梯度换成了文字。

它的命门是评估器。有单元测试这种硬信号才靠谱；靠模型自评，就会变成自我安慰——MBPP 上它就输给了基线。

4两者怎么配合用

管什么信号从哪来什么时候用
Self-Refine一次产出内部的自我修正模型自己的批评（弱信号）写作、改写、格式整理
Reflexion跨轮次的经验积累外部判分（测试、校验、人工）解题、编码、可重试的任务

一定要配外部校验。只靠模型自评的反思，容易出现「越改越偏还很有信心」。跑测试、查数据、人工抽检——任何一种外部信号都比自评强。

今天的对应：Agent 的「错题本」。这也是最实用的一类长期记忆——比存全部对话记录有用得多。

本页要点

  1. Self-Refine：生成 → 批评 → 修改，7 个任务平均提升约 20 个百分点。
  2. Reflexion：Actor 干活、Evaluator 判分、Self-Reflect 写复盘，HumanEval 91% pass@1。
  3. 两者的命门都是评估器：没有硬信号，反思会退化成自我安慰。
  4. 复盘 1–3 条就够，多了会挤占上下文。

★自测

Q1Reflexion 在 MBPP 上为什么输给基线？
有单元测试的 HumanEval 上它很强，没有硬信号的 MBPP 上就失效。评估器的质量决定了这套方法的上限。
Q2「语言强化学习」这个说法指的是什么？
权重一个都没改，改变的是「下一轮的提示里多了什么」。
